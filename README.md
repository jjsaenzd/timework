# Calculadora de Asignación de Tiempo
Selecciona los días y configura los horarios de cada jornada. Ingresa las horas laborales totales y el porcentaje de asignación. La calculadora distribuirá proporcionalmente el tiempo según las horas de cada jornada seleccionada y mostrará el resultado en horas y minutos.
